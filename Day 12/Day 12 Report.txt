2. Usage of config.py vs settings.py 


Config.py :: 

> Used for an environmental specific and external usage
> What goes on here : Values that change between environments and should not affect logic 
> Used to store secret and sensitive info ( like my project id and url )

Settings.py :: 

> What goes on here : Values that define how the app behaves, not where it runs


Purpose ::
> Config.py -> Environment configuration ( tokens & ids )
> Settings.py -> App behavior 
> config.py answers “where & with what” : settings.py answers “how”
